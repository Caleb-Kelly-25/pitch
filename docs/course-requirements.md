# Course Requirements Scope

Pitch began as a team project for a software engineering course. This page records how the delivered project compares with the original requirements document.

## Stretch goals

The requirements task list labeled the following as stretch goals. All were implemented:

- Player profile statistics, shown in a modal in the top bar
- Backend logic for stats and the leaderboard
- Animations for the blind card phase, card movement, and bids

These stretch goals were not completed:

- A tutorial quick-reference pop-up during gameplay
- Two-factor authentication (2FA), labeled "super stretch"

## Beyond the requirements

These features were not in the original requirements document but were added during development:

- AI bot players to fill empty lobby seats
- A leaderboard page with paginated ranked stats
- Ambient music (Web Audio API) with a toggle button
- Sound effects for card play, trick win, and shuffle
- Particle effects and 3D card hover animations

## Cut before development

These were explicitly cut before development began and were never planned: mobile ports (Android, iOS, PWA), in-game chat, keyboard card selection, custom profile photo upload, support for 5 or more players, a dark theme, removing inactive players, and a scrollable rules reference panel.
